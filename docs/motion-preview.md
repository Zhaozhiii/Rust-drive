## 启动与编辑

前端构建使用 Node.js 22 或更新版本，服务端运行不需要 Node.js。

```sh
npm ci
npm run build
```

编辑时运行 `npm run dev`，监听 `frontend/` 并重新生成页面。另开终端启动真实 Rust API 和本地页面：

```powershell
wsl -d Ubuntu-24.04 --cd /mnt/d/Projects/Rust-drive -- python3 tools/preview.py --demo
```

预览地址：<http://localhost:4173/>。工具默认使用 `artifacts/drive-service-preview`，数据在 `artifacts/preview-data/`；`--demo` 只补充不存在的示例文件，Ctrl+C 停止预览及后端。上传和下载均流式代理。

若没有预览二进制，在 Linux/WSL 执行：

```sh
cargo build --release --locked --target x86_64-unknown-linux-musl
mkdir -p artifacts
cp target/x86_64-unknown-linux-musl/release/drive-service artifacts/drive-service-preview
python3 tools/preview.py --demo
```

设置了 `CARGO_TARGET_DIR` 时从实际输出目录复制。修改前端源码后运行 `npm run build` 再刷新浏览器；构建正式二进制前同样先生成前端。

## 体验顺序

1. 右上角按钮展开浅色、深色、跟随系统。选择会保存，跟随系统能实时响应系统变化；Escape 或点击外部收起。
2. 刷新图标至少旋转一圈，请求未结束则继续；重复点击合并请求。
3. 点击名称、大小、修改时间表头，循环升序、降序、默认时间序。默认按现有修改时间从新到旧，目录优先；进入新目录恢复默认，刷新保留排序。
4. 拖入一个文件：FlyingButton 双喷口胶囊跟随，FolderFloat 文件夹打开；松手后胶囊沿弧线缩小入舱，纸张轻落、文件夹合拢。烟雾限于胶囊附近，离开、取消或页面隐藏时停止引擎；无 WebGL 时省略烟雾。点击文件夹同样可选文件。
5. 上传区域底色按实际容量占用从左到右填充，顶部保留容量数字。
6. 单条渐变进度按真实传输字节向前推进，卡片背景同步填充，波浪遮罩、流光与粒子只在上传时播放。暂停后停止动画，已保存分片保留；当前页面直接继续，刷新后重选原文件续传。速度、耗时和预计剩余以紧凑的一行显示，窄屏自动换行。
7. 下载、删除使用带说明的 Lucide 图标按钮。点击垃圾桶时，原有文件行直接进入删除状态，保留原文件名及类型图标；沿用悬浮卡片的同一套透视、指针倾斜和阴影，将抬升加大到 15px、放大到 1.015 倍、倾斜强度加大到 1.6 倍。SlideCommit 与原卡片等宽，普通文件从右端拖到左端松手提交；文件夹的第一次完整滑动只保留划出的背景，并显示 13px、700 字重的“文件夹类型：将删除其中所有文件，再次左滑确认”提醒。第二次从右侧拖动红色垃圾桶，红色轨道铺到最左侧后松手才发送 DELETE。部分滑动回弹、系统触摸取消、取消按钮、Escape 或点击外部均不删除。服务器确认成功后显示“已删除”，再向左淡出文件行并弹出通知；失败保留内容和二次确认状态，可重试。键盘左方向键推进、右方向键退回，End 定位、Enter/空格确认。
8. 桌面鼠标经过文件或文件夹行时，整行以圆角卡片抬升 9px、轻微放大，随指针位置倾斜并显示两层投影。只改变当前卡片，背景、其他行和页头保持原位。原位置的命中区域保持稳定，避免卡片抬升后下边缘闪断；移开、滚动或窗口失焦时清理悬停倾斜。删除状态复用并加强这套效果，抓住垃圾桶期间固定卡片当前角度，避免拖动终点随透视动画偏移，松手后恢复倾斜。触屏不使用悬停倾斜，系统减少动态效果时停止变换。
9. 目录行悬停或键盘聚焦时，闭合图标过渡为打开图标；进入目录时当前卡片给出收束反馈，新目录继续沿用列表入场效果，支持返回上级与连续导航。上传文件夹下方两行文案已删除，保留点击文件夹与拖放操作。
10. 文件列表与上传任务使用本地 SVG 类型图标。接入 [react-file-icon](https://github.com/corygibbons/react-file-icon) 1.6.0（MIT），使用内置类型样式并补充常见代码、影音、压缩、模型和数据格式；未知扩展名显示扩展标签，无扩展名使用通用文件图标，目录使用 Lucide 开合图标。图标不读取文件内容，不请求图片、字体或远端资源。

不再提供筛选框、排序下拉框、工具栏提示文案和页面动效开关。自动尊重系统“减少动态效果”，忽略旧版本的手动动效偏好。

## 源码与兼容

- `frontend/drive.js` 继续管理目录、上传和网络状态，`frontend/effects.jsx` 通过独立挂载点连接 React 组件。
- 原组件位于 `frontend/vendor/react-bits/`，固定到上游提交 `e12c22192ac7b4b452c5e2feb9b586d74765d696`；来源、许可证和适配说明随源码保留。主要 CSS 和物理算法保留，增加业务控制、只读进度和键盘确认。
- React、React DOM、Motion、Matter.js、Lucide 由 esbuild 本地打包，版本由 `package-lock.json` 锁定。不加载 CDN、远程图片、字体或动态脚本。
- `tools/build.mjs` 将组件 CSS 合入 HTML，输出 `web/index.html` 与 `web/app.js`。生成产物纳入版本控制，直接 Cargo 构建仍可用。
- Rust API、数据库、资源路由、Nginx 和流式传输实现不变。SVG、Canvas 和本地打包运行时是本轮明确采用的能力，原生产 CSP 不变。
- React Bits 许可证嵌入生成 JS，其他依赖版权声明由构建器保留。组件用于本网盘应用。
- 文件图标适配位于 `frontend/file-icons.jsx`；新增依赖许可证与 React Bits 一起嵌入构建产物。移除上游 SVG 无用途的固定 `id="file"`，避免和文件输入框冲突，渐变与裁切仍使用库生成的唯一 ID。
